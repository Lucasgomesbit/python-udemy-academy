# 🐍 Python – Udemy Academy

## 📌 Sobre o repositório

Este repositório reúne exercícios, atividades práticas e projetos desenvolvidos durante minha jornada de aprendizado em **Python**, por meio dos cursos da **Udemy Academy**.

O objetivo é documentar minha evolução na programação, colocando em prática os conceitos estudados, desenvolvendo o raciocínio lógico e aprimorando minhas habilidades em desenvolvimento de software.

Aqui estão organizados conteúdos desde os fundamentos da linguagem até projetos práticos, permitindo acompanhar meu progresso ao longo dos estudos.

## 🛠️ Tecnologias e ferramentas utilizadas

As principais ferramentas utilizadas no desenvolvimento dos exercícios e projetos são:

- **Linguagem de programação:** Python 3
- **IDE / Editor de código:** Visual Studio Code (VS Code)
- **Plataforma de aprendizagem:** Udemy Academy
- **Versionamento e armazenamento:** Git e GitHub

## 📚 Conteúdos estudados

O repositório está organizado por categorias de aprendizado:

- Fundamentos de Python
- Variáveis e tipos de dados
- Operadores e expressões
- Estruturas condicionais
- Estruturas de repetição
- Listas, tuplas e dicionários

- Programação Orientada a Objetos (POO)

Utilizar este espaço como um portfólio de estudos e projetos, registrando minha evolução técnica e consolidando os conhecimentos adquiridos durante minha formação em programação.
